The backgrounds use these source SVGs, with their paths preserved and only scale, placement, colour and opacity changed:

- [Gye Nyame](https://commons.wikimedia.org/wiki/File:Gye_Nyame_(Adinkra_Symbol).svg), kasahorow / Openclipart, CC0.
- [Dwennimmen](https://commons.wikimedia.org/wiki/File:Dwennimmen.svg), Pablo Busatto, released into the public domain.
- [Sankofa bird](https://commons.wikimedia.org/wiki/File:Sankofa_bird_symbol.svg), LunaEclipse / Davest3r08, CC0.

Run `node scripts/build-adinkra-pattern.mjs` from `frontend` to regenerate the two self-contained pattern SVGs. Runtime backgrounds do not request external files.
